# S Interior & Construction

Portfolio website for M. Sabry Ismath's architecture, interiors, construction, and CNC signage work.

## Deploy with Vercel

Import this repository into Vercel. The root `vercel.json` configures the portfolio build and static output directory.

## Deploy with GitHub Pages

The `.github/workflows/deploy-pages.yml` workflow builds and deploys the site whenever code is pushed to `main`.

1. Push the repository to GitHub.
2. In the repository's **Settings → Pages**, set the source to **GitHub Actions**.
3. Push to `main` or run the **Deploy portfolio to GitHub Pages** workflow manually.

The site is a static Vite build with no server or environment secrets required.
